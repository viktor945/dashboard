# Порядок

Личный дашборд задач: локальный режим по умолчанию и подключаемый облачный режим Supabase. Интеграции с Битрикс24 пока нет.

## Запуск

Из `/workspace/dashboard`:

```sh
python3 -m http.server 8001 --bind 0.0.0.0
```

Откройте путь `/` через свой способ доступа к серверу. В облачном onboarding предпросмотр не поддерживается. Для локальной работы скачайте проект и запустите ту же команду из корня репозитория.

Зависимости и сборка не требуются: HTML, CSS, JavaScript, Python 3 для статического сервера. Используйте современный браузер и HTTP, а не открытие HTML как файла.

## Возможности

- Быстрый ввод задач, создание своих категорий, группировка и список.
- Приоритет, срок, статус, источник задачи и необязательная ссылка на Битрикс24.
- Мой день, входящие, завершённые, поиск по названию, описанию и заметкам.
- Заметки и события внутри карточки. Изменение статуса записывается в историю.
- Меню «Импорт / экспорт»: читаемый CSV для Excel (UTF-8 с BOM, разделитель точка с запятой, экранирование формул) и резервная копия JSON.
- CSV включает все задачи, заметки и полную хронологию. Это отчёт, обратный импорт CSV пока не поддерживается.
- Восстановление JSON заменяет текущие данные после подтверждения. Файлы Битрикс24 пока не поддерживаются.
- Демопримеры добавляются только по кнопке на пустом экране.

Данные сохраняются в localStorage текущего браузера для конкретного адреса сайта. Между устройствами и браузерами они не синхронизируются. Регулярно делайте экспорт: очистка данных браузера удалит задачи. Одновременное редактирование в нескольких вкладках не поддерживается. Не используйте приложение как единственное хранилище критичных рабочих данных. Нет напоминаний, чата с коллегами или автоматической синхронизации с CRM. Аккаунты и синхронизация устройств требуют подключения Supabase.

## Личный журнал и список задач

В карточке задачи можно отправлять заметки, отчёты и уточнения с датой. Это личный журнал, не общий чат. Кнопка «Добавить список» создаёт по одной задаче на строку (до 500); показывает предпросмотр и пропускает совпадения по названию, не удаляя существующие задачи.

## Аккаунты (требуют подключения Supabase)

См. [SUPABASE_SETUP.md](SUPABASE_SETUP.md). Без заполненного `config.js` приложение продолжает работать локально. Облачный режим хранит отдельный дашборд для каждого аккаунта, проверяет версию перед записью и позволяет перенести локальные задачи явно. Реальная изоляция пользователей должна быть проверена на настроенном проекте перед приглашением отдела.

## Проверки

При запущенном сервере и установленном Playwright + Chromium:

```sh
node tests/backup-export.cjs
node tests/accounts-journal.cjs
```

Другой адрес можно задать через `PORYADOK_TEST_URL`. Тесты используют отдельные браузерные профили, не меняют пользовательские данные. Cloud-тест моделирует API и проверяет поведение клиента при смене аккаунтов, конфликтах, потере сети и выходе во время загрузки. Он не заменяет проверку настоящего Supabase/RLS, описанную в SUPABASE_SETUP.md.
