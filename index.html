Таблица для Excel

Оба планировщика: все задачи, категории, сроки, статусы и заметки в читаемой таблице. Файл CSV открывается в Excel и других табличных редакторах.

Это отчёт для просмотра. Восстановить задачи из этой таблицы пока нельзя.

Резервная копия «Порядка»

Файл JSON сохраняет оба планировщика, все задачи, категории и полную хронологию. Его не нужно читать или редактировать: храните файл, чтобы восстановить данные или перенести их в другой браузер.

Восстановить из резервной копии

Выберите JSON, ранее скачанный из «Порядка». Восстановление заменит текущие задачи и категории после подтверждения. Сначала скачайте копию текущих данных.

Файлы Excel и выгрузки Битрикс24 пока не поддерживаются.

Файлы сохраняются в загрузках браузера. Это ручной перенос данных; автоматической синхронизации между устройствами нет.

Добавить список задач

Раздел: Рабочее. Одна задача на строку. Номера и маркеры списка убираются автоматически. Существующие задачи останутся на месте.

Личный аккаунт

Если пользователь уже создан в Supabase с паролем, войдите с этим email и паролем — письмо не требуется. Новые пользователи входят по приглашению.

Локальные задачи переносятся только по этой кнопке. Существующие облачные задачи сохраняются, совпадающие ID пропускаются.

Без входа задачи остаются только в этом браузере. После входа используется отдельный личный дашборд.

«Порядок» под рукой

Иконка открывает планировщик одним нажатием. Это приложение и ярлык; виджета с задачами на рабочем столе пока нет.

Windows

Откройте сайт в Edge или Chrome. Нажмите кнопку установки выше, если она доступна. В Edge также можно выбрать меню ⋯ → «Приложения» → «Установить этот сайт как приложение». В Chrome ищите «Установить страницу как приложение» в меню браузера.

После установки браузер предложит создать ярлык или закрепить приложение. Можно также скачать обычный ярлык и перенести его из «Загрузок» на рабочий стол:

Файлы .url открывают выбранный раздел в браузере.

iPhone / iPad

  1. Откройте «Порядок» в Safari.
  2. Нажмите «Поделиться» — квадрат со стрелкой вверх.
  3. Выберите «На экран Домой» (иногда нужно прокрутить список действий).
  4. Если есть переключатель «Открывать как веб-приложение», включите его. Нажмите «Добавить».

Android

  1. Откройте сайт в Chrome.
  2. Нажмите кнопку установки выше или меню ⋮ → «Установить приложение» / «Добавить на главный экран».
  3. Подтвердите добавление иконки.

Оба раздела доступны из одной иконки. Для облачных задач нужен интернет. В установленном приложении может потребоваться повторный вход в тот же аккаунт. Локальные задачи между разными браузерами не переносятся автоматически — используйте резервную копию JSON.

Проверка личных данных

Проверим, что один пользователь не может читать или изменять задачи другого. Нужны два разных пустых тестовых аккаунта. Аккаунты с реальными задачами не подходят.

В Supabase → Authentication → Users → Add user создайте два тестовых аккаунта, задайте пароли и подтвердите email через Auto confirm email, если переключатель доступен. Пароли вводятся только здесь и не сохраняются приложением. Если в аккаунте есть задачи, проверка остановится до записи.

Не закрывайте страницу во время проверки. Если очистка не удастся из-за сети, отчёт сообщит об этом. Реальные задачи не используются.
